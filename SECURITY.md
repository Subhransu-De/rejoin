# Security policy

## Supported versions

Security fixes are made on the latest code in the `main` branch and included in the next release. Older releases do not currently receive separate backports.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting on the [rejoin security advisory page](https://github.com/Subhransu-De/rejoin/security/advisories/new). Include:

- The affected version or commit
- Reproduction steps or a proof of concept
- The expected and observed behavior
- The likely impact
- Any suggested mitigation, if known

Reports will be acknowledged through the private advisory. Please allow time to reproduce the issue and prepare a coordinated fix before public disclosure.
